# Reyhan Dekorasyon - Kurumsal Web Sitesi

🌍 **Canlı Site:** [reyhandekorasyon.com.tr](https://reyhandekorasyon.com.tr)

## 📌 Proje Hakkında
Özel mobilya ve iç mekan tasarımı hizmeti veren Reyhan Dekorasyon firması için geliştirilmiş kurumsal web sitesi. Firmanın dijital kimliğini oluşturmak, projelerini ve hizmetlerini müşterilere sergilemek amacıyla hazırlanmıştır.

## 🚀 Üstlendiğim Görevler
* **Web Geliştirme:** Sitenin arayüz (Front-end) ve arka plan (Back-end) kodlamaları.
* **Tasarım:** Marka kimliğine uygun ve kurumsal yapıyı yansıtan UI/UX arayüz düzenlemeleri.
* **Altyapı:** Alan adı (domain) kaydı, Turhost sunucu kurulumu ve sitenin canlıya (deployment) alınması.

## 💻 Kullanılan Teknolojiler
* PHP, JavaScript, HTML, CSS, MySQL
